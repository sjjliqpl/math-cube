# 几何探险所 · 立体图形观察台

一个面向小朋友的 Three.js 立体几何互动网页。选择图形、调整尺寸、切换视角，再用展开动画观察立体图形如何摊平；所有内容都在浏览器中运行，不需要构建工具或后端服务。

## 在线访问

GitHub Pages 部署完成后，可通过仓库的 Pages 地址访问：

```text
https://<用户名>.github.io/<仓库名>/
```

## 功能

- 正方体：调整边长，查看 6 个面、12 条棱和 8 个顶点。
- 长方体：分别调整长度、宽度和高度，观察三组不同大小的面。
- 三角锥：展示四个三角形面与展开动画。
- 多边柱体：自定义底面边数（3–30）、底面半径和柱体高度；每个侧面随机配色。
- 多边锥体：自定义正多边形底面边数（3–30）、底面半径和锥体高度；支持正三棱锥到正三十棱锥。
- 正多面体：下拉选择正四面体、正六面体（立方体）、正八面体、正十二面体或正二十面体，每个面使用随机颜色。
- 其他立体：下拉选择圆锥体、圆柱体或球体。圆锥与圆柱有简化展开图，球体会提示无法完整平面展开。
- 3D 互动：拖动旋转、滚轮缩放、自动旋转，以及前后上下左右六个固定视角。
- 展开图：点击“展开图”按钮，以动画方式在立体状态与平面状态之间切换。
- 透视模式：默认显示不透明实体；点击“透视模式”后显示半透明表面和高亮棱线，便于观察内部结构。
- 全屏观察台：使用右上角全屏按钮放大 3D 观察区域。
- 实时信息：同步显示面数、棱数、顶点数、尺寸和表面积。
- 响应式布局：适配桌面、平板和手机屏幕。

## 本地运行

项目是一个静态网页，直接用浏览器打开也可以运行。推荐使用本地 HTTP 服务，以便浏览器正确处理 ES Module 和 CDN 资源：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173/>。

## 技术栈

- HTML5、CSS3、原生 JavaScript
- [Three.js 0.160.0](https://threejs.org/)
- `OrbitControls` 轨道控制器
- Three.js CDN + import map，无 npm 安装步骤

## GitHub Pages 部署

仓库包含 `.github/workflows/pages.yml`。推送到 `main` 分支后，GitHub Actions 会自动：

1. 检出仓库内容；
2. 将仓库根目录作为静态站点上传；
3. 部署到 GitHub Pages。

也可以在仓库的 **Settings → Pages** 中确认 Source 已设置为 **GitHub Actions**。首次部署通常需要等待几十秒，完成后可在 **Actions** 页面查看日志和站点地址。
